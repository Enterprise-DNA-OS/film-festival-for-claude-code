# Sign off a clear screening as an independent reviewer

Read film-review, screening-schedule and compliance first. A different person from the planner must review the actual documents and all conditions. The attribution label is not authentication. Do not treat a clean check as a legal classification decision.

```bash
npm run festival -- sign-off SHOW1 --reason="Source evidence and projection conditions reviewed" --actor="Your name"
```

Use --dry-run to preview record changes without committing. Every mutation requires --actor with the real operator label.
